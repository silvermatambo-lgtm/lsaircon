# WebDevPro Ultra Max 4 — Changelog

Ultra Max 4 keeps the stable Ultra Max 3 hero/typewriter controller and upgrades the presentation layer.

## Improvements
- Modern display/body typography with subtle oblique styling on major headings.
- Premium five-item mobile footer with colorful gradient icon tiles, depth, micro-motion and active states.
- Rebuilt inline SVG icons for Home, Services, Gallery, WhatsApp and Install.
- Proper, recognizable WhatsApp glyph on the floating assistant and mobile footer.
- WhatsApp assistant waits 20 seconds before automatically opening.
- Auto-open happens only once per browser session to avoid repeated interruptions.
- Existing PWA, service worker, install prompt, hero slider, stable typewriter and Vercel static deployment remain intact.
- Reduced-motion accessibility is respected.
