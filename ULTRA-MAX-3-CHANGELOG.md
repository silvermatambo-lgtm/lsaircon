# Ultra Max 3 Changelog

- Rebuilt the typewriter animation with per-element cancellation.
- Prevented old typewriter timers from continuing after hero slide changes.
- Replaced repeating `setInterval` hero switching with one controlled `setTimeout`.
- Preloads all hero images before rotation.
- Slowed typing/erasing to a smoother professional pace.
- Stabilized hero heading and typewriter heights to prevent layout jumping.
- Pauses animation when the browser tab is hidden and resumes cleanly.
- Added reduced-motion accessibility support.
